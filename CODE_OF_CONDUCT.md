# Code of conduct

This project is for people to work on a tool together. To keep it that way:

- Be respectful. Disagree about the work, not the person.
- Assume good faith, and say plainly when something is unclear instead of guessing.
- No harassment, insults, discrimination or personal attacks, in issues, pull requests, reviews or
  anywhere else the project is discussed.
- Do not share other people's private information.
- Keep to the subject. Requests that ask the project to help get around a network's rules, or to help
  someone attack a system they do not own, are out of scope and will be closed.

The maintainer may edit, hide or remove comments, issues and pull requests that break these rules, and
may block people who keep doing so.

To report a conduct problem, use the private report form described in [`SECURITY.md`](SECURITY.md), or
open an issue that says only that you need to reach the maintainer privately.
